# Registros de homologação

Cada promoção de `develop` para `master` ganha um arquivo aqui, com o nome da versão (ex.: `v1.0.0-rc.1.md`), contendo:

1. O que entrou desde a promoção anterior (PRs).
2. Roteiro de teste.
3. Resultado da validação e quem validou.

Ainda não houve promoção: o ambiente de homologação não existe (ver [MANUAL §2](../MANUAL.md#2-ambientes)).
